# Stronger summaries and Action–Result–Reflection bullets

## Goal
Make every tailored resume open with a confident, role-specific summary and use recruiter-friendly bullets that naturally combine **Action, Result, and Reflection** without showing those labels or inventing facts.

## Changes

### 1. Strengthen the professional summary
- Update the tailoring instructions to produce a confident, ambitious 2–3 sentence value pitch.
- Lead with the target role and strongest verified differentiator, then connect proven technologies and outcomes to the employer’s needs.
- Avoid generic openings, skill-list summaries, clichés, unsupported adjectives, and repeated wording from the job description.
- Keep every claim tied to the candidate’s stored evidence and preserve the compact one-page layout.

### 2. Enforce Action–Result–Reflection writing
- Require each experience and project bullet to read naturally in this order:
  1. **Action:** a strong verb and the specific work performed.
  2. **Result:** a verified outcome, metric, improvement, or delivered capability.
  3. **Reflection:** an integrated closing phrase explaining what the result enabled or why it mattered.
- Keep each bullet to one concise sentence with no visible “Action,” “Result,” or “Reflection” labels.
- When the evidence does not support a metric or broader impact, use only a defensible outcome or significance already present in the record; never manufacture one.

### 3. Preserve quality during claim repair
- Make the flagged-line rewrite step retain the stronger summary voice and Action–Result–Reflection structure while removing unsupported wording.
- Keep the existing evidence validation as the final authority, so style improvements cannot introduce unverified claims.
- If the stored evidence cannot support all three parts, preserve the strongest fully supported Action–Result statement rather than adding a fictional reflection.

### 4. Apply it now and going forward
- Use the revised rules for every newly generated tailored resume.
- Refresh the current tailored resume during the next one-click download, so the existing Application Developer resume receives the improved summary and bullets automatically.
- Keep prior saved versions unchanged for traceability.

### 5. Verify the result
- Add focused tests for summary tone, verb-first bullets, evidence-safe results, and integrated reflection wording.
- Generate and validate a fresh one-click Application Developer resume.
- Visually confirm the PDF remains one-page A4, the summary is stronger, each exported experience/project bullet follows the intended pattern, and no supported section disappears.
- Verify the Word export uses the same revised content and confirm the preview has no build or runtime errors.

## Technical approach
- Refine the generation and repair prompts in the existing tailoring and validation functions; keep the current stored item shape and export renderers unchanged.
- Add a lightweight deterministic bullet-structure check using the existing validation issue reporting, without weakening factual-support checks or changing validation statuses.
- Reuse the current one-click regeneration flow rather than adding another button or step.
